# pyTSXRD
pyTSXRD is a package for analysis of Surface X-ray Diffraction (SXRD) measurements of a polycrystalline surface. The package can be used to map the surface and extract grain-specific diffraction patterns. The notebook is an example of how it can be implemented. For use for data from beamlines other than P21.2 at PETRA III at DESY in Hamburg, the tools might have to be adjusted.

Reference:
H. Sjö, A. Shabalin, U. Lienert, J. Hektor, A. Schaefer, P.A. Carlsson, C. Alwmark, J. Gustafson, Surface grain orientation mapping using grazing incidence X-ray diffraction, Surf. Sci. 754 (2025) 122693. https://doi.org/10.1016/j.susc.2024.122693.

The package is based on py3DXRD (https://github.com/agshabalin/py3DXRD/tree/main) in collaboration with the author.
